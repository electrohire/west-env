This file is the per-version adjustment layer for the five Beningo
Zephyr skills shipped in this image (build-doctor, devicetree-author,
kconfig-tuner, renode-runner, zephyr-bsp-scaffold). The skills
themselves are version-agnostic across Zephyr 4.x; read this overlay
first and let it override any assumption in a skill that conflicts
with the facts below. The image build copies this file to
/opt/zephyr-skills/version-overlay.md.

## What this image actually contains

- Zephyr: exactly v4.4.0. The Python requirements installed are this
  release's own scripts/requirements.txt, nothing unioned from other
  releases.
- Zephyr SDK: exactly 1.0.1, the pin in this release's SDK_VERSION
  file. The SDK ships as the *_gnu bundle and is installed at
/opt/zephyr-sdk; its setup.sh registers the SDK CMake package.
Only the GNU cross toolchains are in this image (the SDK 1.x
LLVM bundle is not installed).
- Board model: hardware model v2 (board.yml with SoC qualifiers),
  as in every Zephyr 4.x release. The bsp-scaffold four-file shape
  (board.yml, .dts, Kconfig.<board>, _defconfig, pinctrl) applies
  as written.
- Workspace layout in the container: /work is the west workspace
  topdir; the Zephyr tree is the workspace's zephyr project, not a
  fixed /workdir/zephyr path.

## Recommended environment (this release's getting-started doc)

Zephyr v4.4.0's getting-started documentation sets these minimums, and
this image is built to meet exactly them:

- CMake >= 3.20.5, Python >= 3.12, Devicetree compiler >= 1.4.6.
- Base image: ubuntu:24.04, whose apt packages provide CMake
  3.28.3 and Python 3.12.3. The base is the oldest Ubuntu that
  meets this release's minimums; it is part of the image tag.
- The apt package set in the image follows the release's Ubuntu
  dependency list (git, cmake, ninja-build, gperf, ccache, dfu-util,
  device-tree-compiler, wget, xz-utils, file, make, gcc and multilib,
  libsdl2-dev, libmagic1, Python with pip, venv and tk).
- west is installed system-wide in the image; a workspace is entered
  with `west init` / `west update` and registered with
  `west zephyr-export`, per the same getting-started flow.

## Skill-specific notes for this version

- Toolchains: GNU cross toolchains only. Do not suggest the LLVM
  toolchain variant (ZEPHYR_TOOLCHAIN_VARIANT=llvm) in this image;
  it is not installed.
- build-doctor: an SDK or requirements mismatch is not a plausible
  cause inside this image; the SDK is this release's own pin. Look
  first at workspace-side causes (overlay, binding, Kconfig).
- renode-runner: the boot banner in the skill's example log is
  illustrative only; this image's builds banner v4.4.0.
- kconfig-tuner / devicetree-author: verify every symbol and binding
  against this image's Zephyr v4.4.0 tree (grep-or-refuse still
  governs); symbols and bindings differ between 4.x releases.
